A faster drop-in for make.fun's csv-reader 1.0.0: `solve.js` answers every case exactly as csv-reader does — same `{columns, rows, errors}`, same broken-CSV error semantics — but reads the text with `indexOf`/`charCodeAt` scans and `slice()` instead of one character at a time. Dependency-free, no caching between cases, deterministic. `main.ts` is the program the harness runs: it reads every case from `/input/cases.json`, answers each with `run`, and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
